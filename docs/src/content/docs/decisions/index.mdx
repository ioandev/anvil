Each page below is a short architecture decision record: **context** (what forced a choice), **decision**,
**consequences** (good and bad) and **alternatives** considered. They exist so that the next person (or the next
Claude session) doesn't re-litigate a choice without knowing why it was made, and can change it knowingly when the
context changes.
