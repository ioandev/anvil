## The model

Every secret file has two forms:

| Form | In git? | Used by |
|---|---|---|
| plaintext working copy (`anvil.env`, `apps/<ns>/prod.env`, …) | **no** (gitignored) | the scripts, on your laptop |
| encrypted twin `<file>.sops` | **yes** | anyone with the age key, to recreate the plaintext |

The list of secret files is `FILES=` in `scripts/secrets.sh`: `anvil.env` (every setting, account key and generated
password: [Variables](/reference/variables/)), each `apps/<ns>/prod.env` and `platform/<ns>/prod.env`,
`infra/terraform.tfstate` (it holds the k3s token), the home machine's vault seal key and secrets files, and the keys
and certificates in `.data/cloudflare-aop/` and `.data/origin-ca/` (twins under `secrets/.data/…`). Files are encrypted in **binary mode**, so a round trip is byte-exact (sops' dotenv mode
is lossy).

Kubernetes Secrets are **generated**, never committed: `scripts/make-secrets.py` builds the gitignored
manifests for the Secret `<ns>` (from `apps/<ns>/prod.env`), `atlas-db`, the platform's own Secrets and the
Prometheus/Alertmanager config, from the plaintext, and `node.sh deploy`
applies them before the app.

## The age key is the root of trust

One age private key decrypts everything: `~/.config/sops/age/keys.txt` on your laptop, plus a copy in your
password manager. The public key is in `.sops.yaml`. **Lose both copies and every secret in git is gone**; leak it
and every secret is exposed. Treat it like the master key it is.

## Daily use

| When | Run |
|---|---|
| after editing any secret | `make secrets-encrypt` |
| first time | `scripts/anvil-secrets init` (creates the age key, `.sops.yaml`, every generated value) |
| fresh clone / new machine | restore `~/.config/sops/age/keys.txt` (mode 600), install `sops` + `age`, then `make hooks secrets-decrypt` |
| adding a secret file | gitignore the plaintext, add it to `FILES` in `scripts/secrets.sh`, `make secrets-encrypt`, commit the `.sops` |
| after `terraform apply` | the state changed: `make secrets-encrypt`, commit |

## The pre-commit hook

`.githooks/pre-commit` (enabled with `make hooks`):

1. re-encrypts changed secret files and stages their twins;
2. refuses the commit if a twin is stale or a plaintext secret is tracked (`scripts/secrets.sh check`);
3. runs `python3 -I scripts/sites.py check` (the [app rules](/reference/app-rules/) it can verify).

## Generated, never typed

Database passwords, the status code, the webhook token, the alerting service password, Grafana's admin password, an
app's `generate:` keys: all random, made by `scripts/anvil-secrets init` (which never changes a value already set);
the origin-pull CA by `scripts/origin-pull-ca`. You never need to remember them; you need the age key.

## A vault for operator credentials (home machine, optional)

Automation that runs without you (the [autopilot](/components/autopilot/)) needs credentials at run time but
shouldn't hold them in plain files forever. An **OpenBao** container on the home machine serves them (set up by
`70-autopilot`, `mac/openbao/`):

- tailnet only (the home machine's `tailscale serve --https=8200`);
- static auto-unseal with a seal key (whose encrypted twin is in git), root token revoked;
- your login, and a read-only **AppRole** `claude` with the `claude-ops` policy (`secret/ops/*`);
- an audit log of every request; a nightly snapshot to local disk (30 days) and to a private bucket with a
  write-only key (90 days). Restore = snapshot + seal key.

<Aside type="note" title="What goes in the vault">
**Only operator/troubleshooting credentials**: the SSH key for the node, the status code and webhook token, the
backup key (for sending email), the age key (for read-only decrypts), the off-site snapshot key. **Never the apps'
secrets**: those stay in SOPS. (On the original server the vault ended up with every app's `prod.env`; anvil doesn't
repeat that.)
</Aside>

## Text Claude writes is scrubbed

Commit messages, post-mortems and published transcripts written by Claude pass through a scrubber: every value
found in the vault (under the redact prefix), known secret values, and anything **gitleaks** flags is replaced with
`[REDACTED]`. When gitleaks is missing, the scripts fall back to a plain file list instead of Claude-written text.

## Rules

- Secrets never go in `app.yaml` or any plaintext tracked file ([rule 8](/reference/app-rules/#8-secrets)).
- Every Secret an app references must exist before it's deployed ([rule 14](/reference/app-rules/#14-every-referenced-secret-exists-first)).
- Never print `anvil.env`; never commit plaintext; never paste secrets into issues or chat (edit the file yourself).
